# Panel Icons

Place the following icon files here for the extension:

- `icon_24.png` - 24x24 pixels
- `icon_24@2x.png` - 48x48 pixels (for high-DPI displays)

## Creating Icons

You can create simple icons using any image editor. The icon should:
- Be a PNG with transparency
- Use simple, recognizable shapes
- Work well at small sizes

Suggested design: A stylized "AP" or podcast microphone icon.
